## About

The Human Resource Management System is a Java-based application designed to manage employee and designation records. It follows a layered architecture that separates business logic, data access, database operations, and presentation components.

The project demonstrates the transition from file-based storage to SQL database storage by changing the database implementation while keeping the higher-level application layers largely unchanged.

## Architecture

- **BL (Business Layer):** Business rules and application logic.
- **DL (Data Layer):** Data access interfaces and operations.
- **DBDL (Database Data Layer):** SQL database implementation.
- **PL (Presentation Layer):** Presentation components and user interaction.

---

## Features

- Employee and designation management
- Employee lookup and validation
- Duplicate PAN and Aadhaar number checks
- Designation-based employee retrieval
- SQL database integration
- Modular, layered application design
- Test cases for employee and designation operations
